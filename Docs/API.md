# API

Base URL

https://resume-api.globe1.online

---

GET

/api/resources

Returns all resumes.

---

GET

/api/resources/latest

Latest entry.

---

GET

/api/resources/next-entry

Returns next serial number.

---

POST

/api/resources/upload

Uploads resume.

---

GET

/api/resources/search

Search candidates.

---

GET

/api/check-phone

Checks duplicate phone.

---

POST

/parse-cv

Parses uploaded CV.
