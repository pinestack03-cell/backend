# Resume Management System

Internal resume management platform developed for Globe1.

## Live

Frontend

https://globe1.online

Backend

## Stack

Frontend

- React
- TypeScript
- TailwindCSS
- Vite

Backend

- Node.js
- Express
- SQLite

Infrastructure

- Vercel
- Cloudflare
- Cloudflare Tunnel
- Windows VPS
- NSSM
